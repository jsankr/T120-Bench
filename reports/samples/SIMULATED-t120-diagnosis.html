CRITICAL: Charging voltage too high

Simulated twin · Charging

Voltage while running15.38 V
Upper limit used15 VIndustry reference

The regulator is not limiting the alternator. Sustained over-voltage boils and swells AGM batteries and can damage lights and electronics.

Likely causes
  1. Regulator/rectifier failed
  2. Regulator sense or earth connection poor
How to check and fix
  1. Avoid long rides until fixed; switch off unneeded loads.
  2. Check the regulator/rectifier connectors and earth under the headlight.
  3. Test the regulator/rectifier (manual p.712–713) and replace if it fails.
Where
  • Regulator/rectifier: At the front, on the fork below the headlight (lower yoke area). To reach it: Visible from the front under the headlight. (manual p.706, tests p.712–713)
  • Battery: Under the seat. The USB socket sits on top of it. To reach it: Remove the seat. (handbook p.16, p.72, p.76)
Sources
  • Industry reference: MotoFOMO: how to test a motorcycle charging system

RESOLVED: Fault code P0605: Engine control module

Simulated twin · Codes

CodeP0605 (stored)Industry reference
Generic meaningControl module ROM errorIndustry reference
SystemEngine control module

The ECM has confirmed this fault and lit the warning lamp.

Likely causes
  1. Connector or wiring for engine control module
  2. The engine control module itself
How to check and fix
  1. Look the code up in the service manual DTC table (p.301–306) to confirm Triumph’s meaning.
  2. Follow the pinpoint test for this system (manual p.289).
  3. Check the connector for this part first: most intermittent codes are connections.
  4. Clear the code only after the fix, then confirm it stays clear on a test ride. Adaption cannot run while an engine code is present (TB 168.2).
Where
  • Engine control module: Shown on the manual’s component-location page. To reach it: See the manual. (manual p.289, pinout p.292)
Sources
  • Industry reference: OBD-II PIDs and generic trouble code definitions (SAE J1979 / J2012)
  • Your service manual (page from your index): Triumph Bonneville T120 Service Manual, 04.2016 issue 1 (your copy)
  • Triumph document: Triumph Technical Bulletin 168 (05.2016): 168.2 Adaptive Fuel System, 168.16 Cooling Fan Fuse Kit
